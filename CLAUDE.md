# Language

Always answer in English, even when my messages are in Spanish (I dictate via voice
mode in Spanish). Only switch languages if I explicitly ask for a response in another
language in that same message.

Course material (slides, student handouts, README files for students) is written in
neutral, impersonal Spanish in manual style: infinitives or "se debe" for steps
("Abrir el navegador", "Se debe salir de la carpeta"), third person for explanations,
no second person at all (no tú, tu, te, usted), no voseo, no regional idioms.
In docente.md files the subject is "el docente". Code, commands, Jenkinsfiles, config, and code comments
stay in English.

# Writing rules

Apply these to all prose output:

- No em dashes.
- No emojis.
1. Never use a metaphor, simile or other figure of speech which you are used to seeing in print.
2. Never use a long word where a short one will do.
3. If it is possible to cut a word out, always cut it out.
4. Never use the passive where you can use the active.
5. Never use a foreign phrase, a scientific word or a jargon word if you can think of an everyday English equivalent.
6. Break any of these rules sooner than say anything outright barbarous.

Review every prose output against these rules before delivering.

# Project

This folder holds the material for the Jenkins class of the UCU DevOps course.
Goal: take students from zero (nothing installed) to a working CI setup with
freestyle jobs, parameterized pipelines, a multibranch pipeline tied to their own
GitHub repo, webhooks, and plugin management.

Students run Jenkins locally with Docker. Assume macOS, Linux, or Windows with
Docker Desktop. Keep every step copy-pasteable.
